## 系统性阅读架构

不是堆书，而是建立一张「认知地图」。

**第一层｜理解世界**
经济学｜宏观经济｜历史｜社会｜哲学｜人文

**第二层｜理解商业**
创业｜战略｜经营｜产品｜营销｜增长｜平台

**第三层｜理解资本**
财务｜金融｜估值｜股权｜融资｜法律｜税务

**第四层｜理解组织**
管理｜组织｜人才｜文化｜领导力｜效率

**第五层｜理解自己**
心理｜决策｜认知｜关系｜创造力

**第六层｜连接现实**
AI｜科技｜媒体｜消费｜新产业｜未来趋势

阅读顺序原则：
**基础认知 → 商业实践 → 产品增长 → 财务资本 → 组织管理 → 科技与未来 → 人文回看。**

书单不是固定课程表，而是动态知识库。每加入一批新书：
1. 去重；
2. 归类；
3. 找出已有体系中的空白；
4. 补充关键经典与反向观点；
5. 调整下一阶段阅读顺序；
6. 已播书籍不重复作为主线，但可在后续专题中回访。

## 核心原则

**书是入口，不是终点。**
从书中获得概念，从现实验证概念，再把验证后的判断沉淀成自己的知识资产。
